# Drift

**English** · [简体中文](README.zh-CN.md)

Pixel skies, playing-card layouts, and room for long reads. A theme for [Hexo](https://hexo.io).

![Drift home page with a pixel starfield, pixel lettering, and post counters](docs/images/home-night.png)

## Try it locally

The example uses Hexo 8 and requires Node.js ≥ 20.19.

```sh
git clone https://github.com/FrostyLeaves/hexo-theme-drift.git
cd hexo-theme-drift/example
npm install
npm run server
```

Open **http://localhost:4000**. The example links directly to the theme source.
